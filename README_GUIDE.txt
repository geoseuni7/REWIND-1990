REWIND 1990 — 두 번째 인생 · 온라인

[핵심 설정]
- 2026년 10월 4일의 인생에서 1990년 1월 1일로 회귀.
- 게임은 1990-01부터 실제 게임 실행일의 연·월까지 월 1회 진행.
- 현재 실행일은 브라우저의 현지 날짜를 사용한다.

[투자]
- 국내 주식 300종 / 해외 주식 300종: 이름·티커 중복 없이 300개씩 구성.
- ETF 50종: 실제 ETF 상품명을 기반으로 구성.
- 주식·ETF는 상장연도 이전 거래 잠금.
- 채권 / 금·원자재 / 암호자산 / 서울 부동산 / 선물·옵션 / 초단타 제공.
- 초단타 그래프는 1초마다 갱신.
- 주식·ETF 매수는 종목별 보유액을 별도로 추적하며 월 결산 때 종목별 변동을 반영.
- 서울 부동산 50종은 매입가격·상장/개발연도·임대수익률·변동성을 가진다.

[생활 밸런스]
- 초과근무: 정확히 +3,000,000원, 즉시 이번 달 턴 종료 후 다음 달로 이동.
- 휴식: 월 1회. 업그레이드형 행동 한도 +1.5, 건강 +5, 스트레스 -12. 휴식은 업그레이드 횟수를 소비하지 않는다.
- 업그레이드형 행동: 기본 월 7회, 휴식 보너스 누적 최대 +5회, 총 최대 12회.
- 보험: 월 50,000원. 월간 대형사고 발생확률 0.1%.
- 보험 가입 시 대형사고 손실의 90%를 보전.
- 은행 대출: 절대 순자산 ×1.5 한도, 월 1% 이자.
- 개인대출: 절대 순자산 ×4 한도, 월 5% 이자.
- 개인대출 12개월 미상환 시 투자자산·현금성 자산을 강제 처분하고 인맥을 0으로 만든다. 남은 대출은 계속 부채로 남을 수 있다.

[인맥]
- 개별 관계는 첫 생성 시 0~30, 일반 관계 최대 50.
- 전체 인맥 50 이상에서 투자 소개 가능.
- 일반 소개: 80% 성공 / 20% 사기.
- 연애 소개: 98% 성공 / 2% 초대형 사기.
- 감정 수치와 캐릭터 커스터마이즈 시스템은 없다.
- 사용자가 자신의 캐릭터 이미지를 직접 업로드한다. 이미지 파일은 4MB 이하로 제한.

[이벤트]
- MAIN 100 / SPECIAL 100 / SOCIAL 100 = 총 300개.
- 세 슬롯은 독립적으로 판정되며 한 달에 0~3개가 동시에 발생할 수 있다.
- 역사적 메인 이벤트는 주요 연도에 강제 등장하며 실행일의 마지막 달도 메인 이벤트 슬롯을 사용한다.
- 이벤트 선택 결과는 현금·시장·부동산·암호자산·부채·직업·건강·인맥·신용 등에 반영된다.

[엔딩]
- 게임 실행일의 연·월에 도달하면 최종 엔딩.
- 자산·부채·건강·인맥·신용과 선택 결과를 함께 평가.

[스트리머 온라인 1년 대전]
- 방당 최대 50명.
- 6자리 방 코드 / 초대 링크.
- 동일 시드 / 동일 시작자산 100,000,000원.
- 12개월 시즌.
- 서버가 월별 변동과 점수를 계산하므로 클라이언트가 임의 점수를 제출할 수 없다.
- 실시간 순위표는 약 2초마다 갱신.
- 서버 메모리 방은 약 6시간 비활동 시 정리된다.
- 서버 재시작 시 방은 사라진다. 영구 계정/글로벌 랭킹은 DB가 필요하다.

[배포]
1. Node.js 18 이상 환경에 파일을 업로드.
2. npm start 또는 node server.js.
3. PORT 환경변수를 제공하면 해당 포트를 사용.
4. Render 등 Node 웹서비스에서는 render.yaml을 사용할 수 있다.
5. 공개 URL을 만든 뒤 그 URL을 스트리머 방송 채팅에 공유하면 시청자가 인터넷으로 접속할 수 있다.

[검수]
- index.html JavaScript 문법 검사 통과.
- server.js 문법 검사 통과.
- 온라인 방 생성 / 참가 / 조회 / 월 진행 / 잘못된 월 거부 테스트 통과.
- 주식 300 + 해외 300 + ETF 50 + 서울 부동산 50 수량 검사 통과.
- 이벤트 300개(M/S/S) 수량 검사 통과.
- 한국식 대형 금액 표시 및 e 표기 제거 검사 통과.
